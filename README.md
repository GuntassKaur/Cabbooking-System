# Cab Booking-System
Cab Booking Management System is a Java Swing–based desktop application developed using NetBeans IDE. It features email-based user authentication, forgot password functionality, and cab detail management. The system uses MySQL with JDBC for secure data storage and efficient database operations.


This is a **Java Swing desktop application** built using **NetBeans IDE** to manage cab bookings. The system is designed to be simple and user-friendly, allowing both **users and admins** to perform their tasks efficiently.

---

## Description

The Cab Booking Management System lets **users sign up and log in**, browse available cabs, and recover their password if they forget it. Admins have their own login to manage the system — they can add, update, or delete cab details and view all bookings.  

Cab information includes the **car name, brand, type, fuel type, price per day, and images**. All data is stored in a **MySQL database**, and database operations are handled using JDBC through a helper class (`DBLoader`).

---

## Features

**User Features:**
- Sign up with email and password  
- Login using email  
- Forgot password to reset credentials  
- Browse available cabs  

**Admin Features:**
- Admin login with secure credentials  
- Add, update, or delete cab details  
- View and manage bookings  

**Other Features:**
- Clean and intuitive GUI with Java Swing  
- Secure MySQL database integration  
- CRUD operations for cab and booking data
